Barreira sanitária
Quem volta do campo entra pelo vestiário sujo, passa obrigatoriamente pelos chuveiros e sai pelo vestiário limpo, com roupa pessoal. Os conjuntos masculino e feminino são independentes.

Estudo preliminar elaborado a partir do Plano de Necessidades para Construção da Base de Endemias (PLN.SVES.001, SVES/SEMUS). Terreno, norte e acesso são hipotéticos; as medidas do desenho são aproximadas. Não substitui o projeto arquitetônico, que depende do terreno real e de profissional habilitado com RRT ou ART.
